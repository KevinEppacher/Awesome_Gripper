# Awesome_Gripper
Mechanical Gripper Development
- 1: ros2 launch gripper_moveit_config demo.launch.py

- 2: ros2 launch gazebo_ros gazebo.launch.py

- 3:Generate the URDF from robot parameter server urdf.xacro 
    ros2 run xacro xacro /app/install/gripper_moveit_config/share/gripper_moveit_config/config/gripper.urdf.xacro -o /tmp/gripper.urdf

- 4: Spawn urdf in gazebo
    ros2 run gazebo_ros spawn_entity.py -file /tmp/gripper.urdf -entity gripper

CHECKS:
- 1: Check Installed ROS 2 Control Packages
     apt list --installed | grep ros-humble
- 2: Check if Controller Plugins Are Available
     ros2 pkg list | grep controller
- 3: Check Controller Manager Plugins
     ros2 param list /controller_manager
- 4: Check for Missing Controller Plugins
     ros2 run controller_manager ros2_control_node --ros-args --params-file /app/install/gripper/share/gripper/config/gazebo_ros2_control.yaml
        If it fails with a plugin-related error, reinstall:
    sudo apt install --reinstall ros-humble-joint-trajectory-controller ros-humble-position-controllers ros-humble-controller-manager
- 5: Command to Check Controller Parameters
     ros2 param list /controller_manager
- 6: Check the available plugin names by running
     ros2 pkg list | grep gazebo_ros2_control
- 7: Check if libgazebo_ros2_control.so is Installed
     find /opt/ros/humble/ -name "libgazebo_ros2_control.so"
- 8: Check if controller_manager is actually running
     ros2 node list | grep controller_manager
- 9: Check robot description:
     ros2 param list | grep robot_description
